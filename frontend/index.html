Ekspor & Data

Unduh data dari empat entitas dalam satu file JSON untuk cadangan, impor backup, atau ekspor laporan booking sebagai CSV.

Data tersimpan di database Supabase. Backup JSON tetap berguna sebagai cadangan, dan bisa diimpor kembali (termasuk backup dari versi localStorage lama).
